## V1.0.0<a name="ZH-CN_TOPIC_0000002550208065"></a>

### 更新说明<a name="ZH-CN_TOPIC_0000002518568282"></a>

在Hadoop集群节点间负载不均衡场景下，OmniScheduler Yarn负载调度算法优化开源版本Capacity Scheduler调度器，拆分为基于物理资源权重计算及排序结果进行资源调度。该算法实现了资源的均衡分配和高效利用。

**新增特性<a name="section9559165534817"></a>**

- 新增支持Yarn容量调度策略按照物理资源和逻辑资源自定义权重排序分配容器。
- 新增兼容Prometheus监控组件采集信息。
- 新增兼容Grafana组件展示集群负载数据。

**修改特性<a name="section299616132492"></a>**

无
