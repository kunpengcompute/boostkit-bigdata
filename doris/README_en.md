## Introduction to the Project<a name="EN-US_TOPIC_0000002553602995"></a>

### Overview<a name="EN-US_TOPIC_0000002522643072"></a>

Doris is a high-performance, real-time analytical database based on MPP architecture, known for its efficiency, simplicity, and unification. It can return query results under massive data in sub-second response time, supporting both high-concurrency point query scenarios and high-throughput complex analysis scenarios. Based on this, Doris can meet usage scenarios such as report analysis, ad-hoc query, unified data warehouse construction, and lake-house integration. Users can build applications such as large-screen dashboards, user behavior analysis, AB experiment platforms, log retrieval analysis, user portrait analysis, and order analysis on top of it.

Doris uses the Bitshuffle algorithm to reorder data, improving the efficiency of LZ4/ZSTD compression algorithms. Doris instruction optimization optimizes the logic of Bitshuffle running on Arm architecture using the NEON instruction set, further improving the efficiency of LZ4/ZSTD compression, thereby improving data writing and query performance of Doris on Kunpeng servers.

The big data Doris instruction optimization feature uses the NEON instruction set to optimize the logic of Bitshuffle running on Arm architecture, improving the compression and decompression speed of LZ4-compressed and ZSTD-compressed data, achieving the goal of improving data query and writing performance, and enhancing data writing and query performance of Doris on Kunpeng servers.


### Application Scenarios<a name="EN-US_TOPIC_0000002522643074"></a>

Bitshuffle is a lossless data compression algorithm that can reduce data storage space while maintaining data precision. It is mainly used in processing scenarios of large scientific datasets (such as meteorological, seismic, and astronomical data). These datasets are usually very large, and data compression can effectively save storage space and improve data transmission efficiency.

Specific application scenarios include:

- Data storage: Save storage space and improve storage efficiency through efficient compression of various types of data.
- Data transmission: Reduce data transmission time and bandwidth consumption, improving transmission efficiency.
- Data backup: Efficiently compress data to reduce the size of backup data and improve backup efficiency.
- Data processing: Compress data before data analysis to reduce the use of computing resources.
